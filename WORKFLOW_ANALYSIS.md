# 1. GitHub Actions Workflow Analysis
- What triggers the workflow?
The workflow runs when code is pushed to the main branch or when a pull request is opened or updated targeting the main branch.
# 2. What are the four main steps in the build-and-test job?
#  The four steps are:
1. **Checkout code:** Retrieves the repository files so the workflow can access the project.
2. **Validate HTML:** Checks the HTML files for errors using an HTML validator.
3. **Check links:** Check links for potential problems. This step uses continue-on-error: true, so a link-check failure will not stop the workflow.
4. **Upload artifact:** Packages the website files so they are ready for deployment to GitHub Pages.
# 3. What does Checkout code do, and why is it necessary?
Checkout code uses the GitHub Actions checkout action to download the repository's files into the workflow's environment. It is necessary because the other steps need access to the project's HTML files and other website resources to validate, test, and prepare the website.
# 4. What is the purpose of the environment configuration?
The environment configuration identifies the deployment environment as github-pages. It also connects the deployment to the website URL generated by the deployment step. This helps GitHub track and manage deployments.
# 5. How does automation improve reliability compared to manual processes?
Automation makes the deployment process more consistent by running the same validation and testing steps whenever changes are pushed to the main branch or a pull request targets it. It helps identify HTML errors and potential broken links before deployment, reduces manual work, and lowers the chance of human error.
# 6. What happens if code is pushed to a branch other than main?
The workflow does not run for a push to another branch because the push trigger only specifies main. However, if a pull request from that branch targets main, the build-and-test job will run. The deployment job will be skipped because deployment only occurs when code is pushed directly to main.
